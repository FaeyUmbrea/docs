# Get social sign-in provider tokens

You can get the OIDC / OAuth 2.0 access, refresh, and ID tokens issued for the identity by social sign-in providers.

Ory Kratos stores two kinds of token sets:

The initial tokens issued upon connecting the provider. These tokens are only issued when the Identity:

- Signs up with a social sign-in provider.
- Links a new social sign-in provider to their account.

The tokens recieved when Kratos last interacted with the provider. These tokens are only issued when and existing Identity:

- Logs in with a social sign-in provider that has been logged in with before

Some providers (i.e. Google) do not send refresh tokens outside of the initial connect request unless the user is shown the consent screen again. In those cases "last_refresh_token" may be emptied once the user logs in again. 
If the application relies on refresh tokens being available, the post login hook should be used to ensure refresh tokens are captured when they are issued.

## Encryption

The Ory Network encrypts these tokens per default at rest using
[XChaCha20 Poly1305](https://en.wikipedia.org/wiki/ChaCha20-Poly1305#XChaCha20-Poly1305_–_extended_nonce_variant).
